# Status Changes

Retirements, merges, and renames in the agent-orchestration landscape, newest first. Verified on official sources 2026-09-29.

## 2026

- **Semantic Kernel superseded by Microsoft Agent Framework 1.0** (Apr 2026) — per SK's own README; migration guides point to `microsoft/agent-framework`.
- **AutoGen in maintenance mode** (by 2026) — community-managed, no new features; Microsoft directs new users to Microsoft Agent Framework. AG2 continues the AutoGen line as a community project (AG2 Classic holds the original codebase).
- **Meta's Llama Stack → OGX (independent)** — Meta's open-source agentic API server moved to independent stewardship as OGX; there is no product called "Meta Agentic Orchestration."
- **Vertex AI Agent Engine → Gemini Enterprise Agent Platform** — Google's managed runtime rebranded (with an Agent Runtime); distinct from the employee-facing Gemini Enterprise (ex-Agentspace).
- **Google Agentspace → Gemini Enterprise** — the employee-facing governed AI platform renamed.
- **Azure AI Foundry → Microsoft Foundry** — managed multi-agent orchestration rebranded (Agent Service).
- **AWS `multi-agent-orchestrator` → Agent Squad (2FastLabs)** — moved off AWS Labs; no longer an AWS offering.
- **`explodinggradients/ragas` → `vibrantlabsai/ragas`** — repo move with org rename.
- **Flowise archived** — the low-code agent builder is a public archive ("Refer to Future of Flowise").
- **HumanLayer SDK deprecated** — the cross-framework HITL SDK is deprecated per its own README; development moved to a coding-agent rebuild.

## 2025

- **ACP merged into A2A** (~Sept 2025) — IBM/BeeAI's Agent Communication Protocol archived and merged into the Linux Foundation's Agent2Agent Protocol. Build on A2A.
- **LangGraph Platform → LangSmith Deployment** (Oct 2025) — managed deployment renamed; the LangGraph framework stays MIT.
- **AP2 donated to FIDO Alliance** (Apr 2026 announced earlier — standardization track) — Google's Agent Payments Protocol under FIDO stewardship.
- **Community Edition of Zep deprecated** (Apr 2025) — OSS effort continues as Graphiti.
